# End-to-end demo run, Monday 2 November 2026

**Result: passed.** The live bot ran for two hours on the Deriv demo account with a real
candidate, took a genuine signal, survived a forced disconnect, answered Telegram commands,
closed everything on /stop and shut down cleanly. No real money was involved at any point.

Plain-language summary: this was the first time the whole bot ran end to end against Deriv
rather than against a mock. Everything it is supposed to do, it did. One small logging bug
was found and fixed (see below). The one trade the strategy took lost 0.60 USD, which says
nothing about the strategy: it was cut short by the planned /stop after 54 minutes.

## Checks against the hard rules

- Stake 3.00 USD = 3% of the 100 USD ledger; multiplier x100; one trade per pair; at most two open.
- The cost gate read the commission in each quote and compared it with 1.5x the pair's base rate.
- Every signal, order, quote, close and command is in the SQLite journal (16 quotes journalled).
- Kill switch, daily loss limit and the 20:30 Friday deadline were armed (deadline visible on the order) but not reached.
- Real money is impossible in this configuration: `DERIV_MODE=demo`, and real mode is refused anyway without a graduated candidate and `CONFIRM_REAL=yes`.

## Bug found and fixed

The journal entry for a test-trade request raised "Journal.event() got multiple values for
argument 'symbol'", because the request file also contains a `symbol` key. The error was
caught and logged as `test_trade_refused`, but the trade itself still went ahead, so the
journal was misleading rather than the behaviour wrong. Fixed in `take_test_requests`
(the symbol is no longer passed twice) with a regression test.
